# PyTorch CPU build
# -----------------
# The `+cpu` local version is load-bearing: a plain `pip install torch==2.4.1`
# resolves a CUDA-enabled build on many platforms, silently pulling gigabytes of
# GPU runtime and changing which kernels execute. The index URL below makes the
# CPU build resolve deterministically.
#
# Verify after installing:
#   python -c "import torch, torchvision; print(torch.__version__, torchvision.__version__, torch.cuda.is_available())"
#   expected: 2.4.1+cpu 0.19.1+cpu False
#
# For a GPU machine, drop the --index-url line and install the CUDA build from
# https://pytorch.org/get-started/locally/ instead.
